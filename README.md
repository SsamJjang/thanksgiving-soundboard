# Thanksgiving Soundboard

Open `index.html` in a browser (double-click works, no server needed).

All sound effects are listed in one table. Click a row to play it, click again to stop.

Hotkeys only for the quiz cues:

| Key | Sound |
| --- | --- |
| 1 | Question Reveal |
| 2 | Timer Running (loops by default) |
| 3 | Hold Up Answer |
| 4 | Answer Reveal |

- **Shift + 1–4** fades out that cue
- **Space** fades out everything, **Esc** stops everything
- **↑ / ↓** master volume
- *Cues 1–4 stop each other*: starting one cue fades out the other cues, so pressing 3 cuts the timer
- Each sound has its own volume, loop toggle, and a clickable position bar for seeking; settings are remembered

`grand_intro` was converted from WMA to M4A because browsers can't play WMA.
